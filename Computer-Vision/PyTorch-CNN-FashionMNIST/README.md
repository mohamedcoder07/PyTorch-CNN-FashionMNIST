# FashionMNIST Classification with PyTorch


This project is a practical hands-on tutorial for exploring Computer Vision using PyTorch. It demonstrates how to build, train, and evaluate a Convolutional Neural Network (CNN) to classify clothing items from the FashionMNIST dataset.


## Project Structure


1.  **`cnn.ipynb`**: The main notebook containing the data exploration, training loop, and visual results.
2.  **`model.py`**: Contains the Model_cnn class and the train_eval_model utility function.



## Results & Inference

The model typically achieves over 90% accuracy on the validation set after 15 epochs.

The project also features a prediction section where the model classifies external images (like boots or trousers) after they are preprocessed to match the training data format (28x28 grayscale).
